# AI 编程工具使用及 AI 代码生成率统计说明（群通知版）

公司正在积极推进“AI+”赋能研发提效。对研发同学来说，真正能带来明显效率提升的方式，是使用 AI 编程工具的智能体或对话式能力进行编码，而不仅仅是依赖 `Tab` 补全完成简单代码续写。

鉴于集团基于研发云 CodeFree 的相关考核尚未正式发布，现阶段建议大家先使用行业主流 AI 编程工具开展实践，提前熟悉主流 AI 编程能力，也为后续 CodeFree 的推广和优化提供参考。

## 推荐工具

- Cursor（1.7 及以上）
- Claude Code
- GitHub Copilot
- Google Gemini CLI
- Continue CLI
- OpenCode
- Atlassian RovoDev

> 其他工具暂不支持统一统计，如需纳入口径，请切换至上述推荐工具。

## 统计口径

纳入统计的范围为：通过与 AI 智能体或对话交互生成的代码。

以下内容默认计为人工编写代码，不纳入 AI 生成率统计：

- Tab 补全生成的代码
- 页面内快速编辑生成的代码

## 使用要求

1. 安装 `git-ai` 插件：  
   <https://alidocs.dingtalk.com/i/nodes/MNDoBb60VLrrkgAXSPvKRxxq8lemrZQ3?utm_scene=person_space>
2. 使用推荐的 AI 编辑器或智能体进行开发
3. 将 AI 生成的代码通过 Git 提交并推送到远程仓库
4. 为 `leijiawei` 账号开通仓库访问权限，便于项目配置和后续数据查询

建议由组长统一配置权限并汇总项目地址，发送给雷加伟，由其统一完成配置。配置完成后，即可查询对应项目的 AI 代码生成率。
