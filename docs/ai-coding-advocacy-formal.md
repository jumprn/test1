# AI 编程工具使用及 AI 代码生成率统计说明

## 一、背景说明

公司目前正在积极推进“AI+”赋能办公生产。对于研发岗位而言，最直接、最有效的提效方式，是使用 AI 编程工具中的智能体（Agent）或对话式能力参与编码，而不仅仅停留在通过 `Tab` 键进行简单代码补全的层面。

目前，集团基于研发云 CodeFree 的相关考核方案尚未正式落地。在此之前，建议大家优先使用行业内较为主流的 AI 编程工具开展日常研发工作。一方面，可以帮助大家建立对主流 AI 编程能力的认知；另一方面，如果后续公司正式推进 CodeFree 插件，也便于大家基于已有使用经验，对公司工具能力提出更有针对性的优化建议。

## 二、推荐使用的 AI 编程工具

目前建议使用以下主流 AI 编程工具进行开发：

- Cursor（版本建议 1.7 及以上）
- Claude Code
- GitHub Copilot
- Google Gemini CLI
- Continue CLI
- OpenCode
- Atlassian RovoDev

> 说明：以上工具支持后续相关统计或数据提取。  
> 其他工具暂不支持统一统计，如需纳入口径，请切换至上述推荐工具使用。

## 三、AI 数据统计范围

本次 AI 数据提取的范围为：

- 通过与 AI 智能体或对话交互生成的代码

以下场景不纳入 AI 生成代码统计，默认划分为人工编写代码：

- 使用 `Tab` 键触发的代码补全
- 在编辑器页面内通过快速编辑等方式生成的内容

## 四、AI 数据提取要求

为保证 AI 代码生成率能够被准确统计，请按以下要求执行：

### 1. 安装 git-ai 插件

请先安装 `git-ai` 插件：  
<https://alidocs.dingtalk.com/i/nodes/MNDoBb60VLrrkgAXSPvKRxxq8lemrZQ3?utm_scene=person_space>

### 2. 使用推荐的 AI 编辑器或智能体开发

请尽量使用上述推荐的 AI 编程工具，并通过智能体或对话式方式参与开发，以确保统计口径一致。

### 3. 通过 Git 提交并推送代码到远程仓库

通过 AI 编程工具生成的代码，需要按规范进行：

- 本地提交（commit）
- 推送（push）到远程仓库

这也意味着，你开发的项目需要托管在研发云仓库或团队自己的 Git 仓库中，才能进行后续统计。

### 4. 为指定账号开通仓库访问权限

请为 `leijiawei` 账号添加对应仓库的访问权限，便于进行项目配置和数据查询。

建议由各组组长统一完成权限配置，并将项目地址统一发送给雷加伟。待雷加伟完成一次性配置后，即可查询对应项目的 AI 代码生成率等相关数据。
